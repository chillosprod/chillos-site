A system that belongs to the curious

An operating environment designed to be understood.

ChillOS is not trying to hide its moving parts. It gives developers and explorers a visual place to test ideas, inspect behavior and recover from mistakes.

01

Open by default

The project lives on GitHub and is distributed under Apache License 2.0, with additional product terms.

02

Local-first

Profiles, language preferences and virtual files are intended to stay on the user’s device.

03

Recovery is a feature

The Recovery Environment and isolated disk model make experiments less intimidating.

Core capabilities

PCHLLKernel

A visible kernel layer.
